Band limits

Load a codeplug to see the band limits.

The two VFOs are the frequencies each side of the display falls back to when you leave the memory channels. They live in their own records past the 200 channels, have no names, and never appear when you scroll.

This radio also carries a 220 MHz slot for each VFO, inherited from a tri-band sibling. It has no such band, so those two are left exactly as they are.

FM broadcast presets

Presets

Thirty-two stored FM broadcast stations, in MHz. Tick a preset to mark it in use; blank the frequency to store nothing in that slot. The per-preset tick boxes are the one part of this block that was inferred rather than confirmed against a radio.

Appearance

Your choice, the panel width and the transfer options below are remembered on this computer. Codeplugs never are — a stale one reappearing after a refresh is exactly how the wrong thing gets written to a radio.

When talking to the radio

Verification reads the codeplug back after writing and compares it byte for byte. Comparing first shows you what would change before anything is sent. Legacy framing is for units that use the older frame format.

About this tool

The protocol here was recovered by reading the manufacturer's own programming software rather than from a captured session. Read your radio and save that file before you write anything — it is your way back.

The radio speaks USB directly — its microcontroller presents a virtual COM port — so the baud rate is not something worth adjusting if a transfer misbehaves.

If the handshake fails, try Legacy framing: this radio family appears to use two different frame formats with identical commands.

Inverted DCS is the one field known to be uncertain. If polarity comes out backwards, the encode and decode inversion bits need swapping.
